## 固定业务边界

- 申请类型固定为差旅、采购、报销和加班，不支持运行时自定义表单。
- 使用进程内存仓储，不接数据库；服务重启后恢复预置数据。
- 审批人固定为李经理，采用单级审批，不做多级审批、会签、加签或动态审批流。
- 不实现附件上传、发票图片、多行采购/报销明细、消息通知和复杂 RBAC 管理后台。
- 员工只能操作自己的申请，审批人查看非草稿申请并执行审批。
